# Tailoring advice: Work Package structuring — Change Control (Containment Strategy) stream

Source of advice: method-tailoring-practitioner specialist, 2026-09-09.
Based on: sources/modernisation/change-control-containment-strategy-pbs.md
Status: RECOMMENDATION — not yet approved by Project Manager.

## Recommended structure
Four Work Packages, one per Level 2 stream:
1. WP1 — Change and Comms Plan
2. WP2 — Jira Service Management (JSM) Portal
3. WP3 — Processes
4. WP4 — CAB / CCB

Rationale: the four streams differ materially in delivery character. JSM
Portal (WP2) suits iterative/incremental build-and-test. The other three are
largely one-off document/process authoring converging on stakeholder
sign-off. A single combined package would obscure progress on faster
streams behind slower ones. Splitting to individual-product level is
premature — most Level 4 items are still unnamed ("xxx").

## Content notes per stream (source material observations)
- WP1 (Change and Comms Plan): includes a Change Plan, a Comms Plan, and a
  third unlabelled Level 3 column — products largely undefined (xxx
  placeholders).
- WP2 (JSM Portal): Customer Service Agent, Knowledge Base, Workflows,
  Testing — genuinely unnamed Level 4 items, suited to becoming backlog
  items once named. Related items: Establish Training process, Define
  flows w/in branches, Form Templates, Jira Workflows, Governance Document.
- WP3 (Processes): Triage Process, Mod Branch Process, Training. Level 4
  items here ("Process Map", "Instructions", "Templates") look like
  Product-Description-level categories rather than individual tasks —
  treat as pointers to what each product's Product Description should
  specify, not as products themselves.
- WP4 (CAB/CCB): Change types, Change Impact Process, TOR, Release Process.
  This stream is about Enabling Services BUILDING the CAB's governance
  artefacts (TOR, change types, release process) — not about Enabling
  Services becoming or convening the CAB itself. Keep this distinction
  explicit in the Work Package description.
